**Goal:** Add a `show` URL param that reveals 10 / 20 / all rows per tab with a "Showing X of Y" + "Read more"/"Show all" link, and restyle the per-row action controls with a consistent outlined button look plus a visible disabled state.

**Architecture:** `show` is parsed, applied, and labeled by new pure functions in `src/lib/vacancyActions/vacancyTabs.ts`, wired into the existing `getVacancyTabData()` orchestrator, and rendered by a new `VacancyPagination` component below `VacancyTable`. `VacancyTabs`'s existing tab/reason links gain a `show` prop so they carry it forward. None of this touches Supabase, schema, or the row-cap pagination (`fetchAllRows`) added by the prior step — this is purely a UI-facing re-slice of rows already in memory.

**Tech Stack:** Next.js App Router (Server Components + plain `<Link>` navigation, no client state), TypeScript, Vitest + Testing Library (jsdom for components), Tailwind CSS v4.

## Global Constraints

- URL param `show`: absent → 10 rows, `"20"` → 20 rows, `"all"` → every row, any other value → 10 rows (same fallback pattern as the existing `view`/`reason` params).
- Rows are sliced on the server **after** the existing tab (`view`) and reason filters, never before — tab counts (`counts.todo/applied/ignored/all`) stay computed over every vacancy, unaffected by slicing.
- "Showing X of Y" renders below the table only when the tab (post tab+reason filter, pre-slice) has more than 10 rows.
- Link choice: showing 10 of more → "Read more" (`show=20`); showing 20 of more → "Show all (Y)" (`show=all`); every row visible → no link.
- `show` must be preserved on the existing tab links and reason-filter links. `view` and `reason` must be preserved on the new "Read more"/"Show all" links.
- Async Server Components (`page.tsx`) are never rendered in tests — all parsing/slicing/labeling logic lives in plain, directly-testable functions, matching the existing `resolveView`/`resolveReasonFilter`/`selectRowsForView`/`countByView` pattern in `src/lib/vacancyActions/vacancyTabs.ts`.
- One concern per commit (project convention) — see each Task's step list for the exact commit boundaries.
- `npm test` and `npm run build` must both pass before this is done.
- Work happens on a new branch `feat/read-more` created from `main`, in place (no worktree).
- Neither Task 1 nor Task 2 gets a per-task review. Task 2 is checked on a Vercel Preview deploy by the user. A single final whole-branch review runs after both tasks, per the user's explicit instructions below.
- Never read, print, or log `.env.local` values. No schema-changing or destructive SQL is involved in this step.

## Review Focus

- **Off-by-one at the tier boundaries.** A tab with exactly 10 rows must show no "Showing" line at all (not "more than 10"); a tab with exactly 20 rows at `show=20` must show no link (every row already visible). Both are explicit required test cases below.
- **`filteredCount` vs. tab `counts` conflation.** On the `ignored` tab with a reason filter active, the "Showing X of Y" total must reflect the reason-filtered row count, not `counts.ignored` (which is always the unfiltered total). Mixing these up would show a `Y` larger than what "Show all" would ever actually reveal.
- **Dead-end "Read more" / "Show all" links.** The generated link's `show` value must be exactly `"20"` or `"all"` — a typo or wrong casing would make `resolveShow` silently fall back to 10, so clicking "Read more" would appear to do nothing.
- **Array-valued search params.** Next.js gives `string[]` for a repeated query key (e.g. `?show=20&show=all`); `resolveShow` must take the first element like the existing `resolveView`/`resolveReasonFilter` do, not throw or silently return something unexpected.
- **Losing `show` on an unrelated navigation.** Switching tabs or the reason filter must not silently reset an explicit `show=20`/`show=all` back to the 10-row default — this is easy to miss if `show` is wired into only one of the two link builders in `VacancyTabs.tsx`.

export type ShowParam = 10 | 20 | "all";

export function resolveShow(value: string | string[] | undefined): ShowParam {
  const candidate = firstOf(value);
  if (candidate === "20") {
    return 20;
  }
  if (candidate === "all") {
    return "all";
  }
  return 10;
}

export function sliceRowsForShow(rows: VacancyTabRow[], show: ShowParam): VacancyTabRow[] {
  return show === "all" ? rows : rows.slice(0, show);
}

export function describeShownRows(
  filteredCount: number,
  show: ShowParam
): { shown: number; total: number; more: { label: string; show: "20" | "all" } | null } | null {
  if (filteredCount <= 10) {
    return null;
  }
  const shown = show === "all" ? filteredCount : Math.min(show, filteredCount);
  if (shown >= filteredCount) {
    return { shown: filteredCount, total: filteredCount, more: null };
  }
  if (show === 10) {
    return { shown, total: filteredCount, more: { label: "Read more", show: "20" } };
  }
  return { shown, total: filteredCount, more: { label: `Show all (${filteredCount})`, show: "all" } };
}
```

import "server-only";

import { getVacancies } from "@/lib/vacancies/getVacancies";
import { getVacancyStatuses } from "./getVacancyStatuses";
import {
  buildVacancyTabRow,
  countByView,
  resolveReasonFilter,
  resolveShow,
  resolveView,
  selectRowsForView,
  sliceRowsForShow,
  type ShowParam,
  type VacancyTabCounts,
  type VacancyTabRow,
  type VacancyTabView,
} from "./vacancyTabs";
import type { IgnoreReason } from "./types";

export type VacancyTabSearchParams = {
  view?: string | string[];
  reason?: string | string[];
  show?: string | string[];
};

export type VacancyTabData = {
  view: VacancyTabView;
  reasonFilter: IgnoreReason | "none" | null;
  counts: VacancyTabCounts;
  rows: VacancyTabRow[];
  show: ShowParam;
  filteredCount: number;
};

export async function getVacancyTabData(params: VacancyTabSearchParams): Promise<VacancyTabData> {
  const [vacancies, statuses] = await Promise.all([getVacancies(), getVacancyStatuses()]);

  const allRows = vacancies.map((vacancy) =>
    buildVacancyTabRow(vacancy, statuses.get(vacancy.id) ?? { status: "todo" })
  );

  const view = resolveView(params.view);
  const reasonFilter = resolveReasonFilter(view, params.reason);
  const show = resolveShow(params.show);
  const filteredRows = selectRowsForView(allRows, view, reasonFilter);

  return {
    view,
    reasonFilter,
    show,
    counts: countByView(allRows),
    rows: sliceRowsForShow(filteredRows, show),
    filteredCount: filteredRows.length,
  };
}
```

```tsx
import Link from "next/link";
import type { ShowParam, VacancyTabCounts, VacancyTabView } from "@/lib/vacancyActions/vacancyTabs";
import type { IgnoreReason } from "@/lib/vacancyActions/types";

const TABS: { view: VacancyTabView; label: string }[] = [
  { view: "todo", label: "To do" },
  { view: "applied", label: "Applied" },
  { view: "ignored", label: "Ignored" },
  { view: "all", label: "All" },
];

const REASON_FILTERS: { value: string | null; label: string }[] = [
  { value: null, label: "All reasons" },
  { value: "language", label: "Language" },
  { value: "location", label: "Location" },
  { value: "seniority", label: "Seniority" },
  { value: "other", label: "Other" },
  { value: "none", label: "No reason" },
];

function showQuery(show: ShowParam): string | null {
  return show === 10 ? null : String(show);
}

function tabHref(view: VacancyTabView, show: ShowParam): string {
  const params = new URLSearchParams({ view });
  const showValue = showQuery(show);
  if (showValue) {
    params.set("show", showValue);
  }
  return `/?${params.toString()}`;
}

function reasonHref(reasonValue: string | null, show: ShowParam): string {
  const params = new URLSearchParams({ view: "ignored" });
  if (reasonValue) {
    params.set("reason", reasonValue);
  }
  const showValue = showQuery(show);
  if (showValue) {
    params.set("show", showValue);
  }
  return `/?${params.toString()}`;
}

export function VacancyTabs({
  view,
  counts,
  reasonFilter,
  show,
}: {
  view: VacancyTabView;
  counts: VacancyTabCounts;
  reasonFilter: IgnoreReason | "none" | null;
  show: ShowParam;
}) {
  return (
    <>
      <nav aria-label="Vacancy tabs" className="mb-4 flex gap-4 border-b border-zinc-200 dark:border-zinc-800">
        {TABS.map((tab) => (
          <Link
            key={tab.view}
            href={tabHref(tab.view, show)}
            aria-current={view === tab.view ? "page" : undefined}
            className={`pb-2 text-sm ${
              view === tab.view
                ? "border-b-2 border-black font-semibold text-black dark:border-white dark:text-white"
                : "text-zinc-600 dark:text-zinc-400"
            }`}
          >
            {tab.label} ({counts[tab.view]})
          </Link>
        ))}
      </nav>

      {view === "ignored" && (
        <nav aria-label="Ignore reason filter" className="mb-4 flex gap-3 text-sm">
          {REASON_FILTERS.map((filter) => (
            <Link
              key={filter.label}
              href={reasonHref(filter.value, show)}
              aria-current={reasonFilter === filter.value ? "page" : undefined}
              className={
                reasonFilter === filter.value
                  ? "font-semibold text-black dark:text-white"
                  : "text-zinc-600 dark:text-zinc-400"
              }
            >
              {filter.label}
            </Link>
          ))}
        </nav>
      )}
    </>
  );
}
```

import Link from "next/link";
import { describeShownRows, type ShowParam, type VacancyTabView } from "@/lib/vacancyActions/vacancyTabs";
import type { IgnoreReason } from "@/lib/vacancyActions/types";

function moreHref(
  view: VacancyTabView,
  reasonFilter: IgnoreReason | "none" | null,
  show: "20" | "all"
): string {
  const params = new URLSearchParams({ view });
  if (reasonFilter) {
    params.set("reason", reasonFilter);
  }
  params.set("show", show);
  return `/?${params.toString()}`;
}

export function VacancyPagination({
  view,
  reasonFilter,
  show,
  filteredCount,
}: {
  view: VacancyTabView;
  reasonFilter: IgnoreReason | "none" | null;
  show: ShowParam;
  filteredCount: number;
}) {
  const summary = describeShownRows(filteredCount, show);
  if (!summary) {
    return null;
  }

  return (
    <div className="mt-3 text-sm text-zinc-600 dark:text-zinc-400">
      <p>
        Showing {summary.shown} of {summary.total}
